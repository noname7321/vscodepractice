enumerate 的作用是：遍历列表时，同时得到“当前位置编号”和“当前位置的元素”。
torch.arrange(start, end, step) 生成一个一维张量，包含从 start 到 end（不包括 end）之间的值，步长为 step。
torch.rand(n) 生成一个形状为 (n,) 的一维张量，元素为 [0, 1) 区间的均匀分布随机数。
torch.randn(n) 生成一个形状为 (n,) 的一维张量，元素为标准正态分布的随机数。

zip 的作用是：将多个可迭代对象“打包”成一个可迭代对象，遍历时同时得到每个可迭代对象的当前位置的元素。按照第一个可迭代对象的长度来决定遍历次数，长度不够的可迭代对象会被截断。

subplots 的作用是：在同一个图中创建多个子图。内部的参数包括：nrows, ncols，参数 sharex=True, sharey=True 表示所有子图共享 x 轴和 y 轴的刻度。figsize=(width, height) 表示图的宽度和高度，单位为英寸。squeeze=False 表示即使只有一行或一列子图，也保持 axes 为二维数组。axes 是一个二维数组，表示所有子图的坐标轴对象。enumerate(zip(axes, matrices)) 的作用是：同时遍历 axes 和 matrices，得到每一行的坐标轴对象和矩阵。
subplots 返回的 fig 是图像对象，axes 是一个包含所有子图坐标轴对象的数组,
通常写作 fig, axes = plt.subplots() 。

.detach() 的作用是：将一个张量从计算图中分离出来，返回一个新的张量，且不需要梯度计算。.detach().numpy() 的作用是：将一个张量转换为 NumPy 数组。

plt.colorbar() 的作用是：在图像中添加表示“颜色对应多大数值”的颜色条。其内部参数主要包括：mappable 表示要添加颜色条的图像对象，ax 表示要添加颜色条的子图坐标轴对象，shrink 表示将颜色条的长度缩为默认长度的多少。举一个具体的例子，mappable=pcm 表示要添加颜色条的图像对象是 pcm，ax=axes 表示要添加颜色条的子图坐标轴对象是 axes，shrink=0.6 表示将颜色条的长度缩为默认长度的 60%。

torch.rand()内部的参数包括：size 表示生成张量的形状，dtype 表示生成张量的数据类型，device 表示生成张量的设备，requires_grad 表示生成张量是否需要梯度计算。torch.randn()内部的参数包括：size 表示生成张量的形状，dtype 表示生成张量的数据类型，device 表示生成张量的设备，requires_grad 表示生成张量是否需要梯度计算。

torch.rand(2,2,4)的含义是：生成一个形状为 (2, 2, 4) 的三维张量，元素为 [0, 1) 区间的均匀分布随机数。torch.randn(2,2,4) 的含义是：生成一个形状为 (2, 2, 4) 的三维张量，元素为标准正态分布随机数。

torch.rand() torch.randn() 的区别是：torch.rand() 生成的是 [0, 1) 区间的均匀分布随机数，torch.randn() 生成的是标准正态分布随机数。(torch.rand(n) * 5)的含义则是：生成一个形状为 (n,) 的一维张量，元素为 [0, 5) 区间的均匀分布随机数。torch.randn(n) 生成一个形状为 (n,) 的一维张量，元素为均值为 0、标准差为 1 的正态分布随机数。

torch.eye(n) 生成一个 n×n 的单位矩阵。reshape((1, 1, n, n)) 将其形状改为 (1, 1, n, n)，以便与多头注意力机制的输出形状一致。

torch.sort() 的作用是：对一个张量进行排序，返回排序后的张量和对应的索引。其内部参数主要包括：dim 表示要排序的维度，descending 表示是否按降序排序。

lambda 的作用是：创建一个匿名函数。其内部参数主要包括：x 表示函数的输入，冒号后面表示函数的返回值。举一个具体的例子，lambda x: torch.exp(-0.5 * x ** 2) 表示创建一个匿名函数，其输入为 x，返回值为 torch.exp(-0.5 * x ** 2)。x **2 表示 x 的平方，torch.exp() 表示计算 e 的幂次方。

-1e6代表的意思是10的负六次方，即0.000001。它通常用于在计算中表示一个非常小的数值，接近于零。在深度学习中，-1e6 常用于掩码操作（masking），例如在注意力机制中，将某些位置的注意力权重设置为一个非常小的值，以便在 softmax 计算中几乎忽略这些位置，从而实现对特定位置的屏蔽效果。
